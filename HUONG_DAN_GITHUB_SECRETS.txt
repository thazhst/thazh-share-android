================================================================================
HƯỚNG DẪN THIẾT LẬP GITHUB SECRETS CHO DỰ ÁN THAZH SHARE (com.thazh.share)
================================================================================

Tài liệu này hướng dẫn chi tiết từng bước cách thiết lập các biến bảo mật (GitHub
Secrets) trong kho lưu trữ GitHub của bạn. Toàn bộ các tệp keystore trong kho mã
nguồn đã được loại bỏ để bảo mật, và GitHub Actions (`.github/workflows/build.yml`)
sẽ sử dụng trực tiếp:
  1. `GOOGLE_SERVICES_JSON`    : Tự động tái tạo tệp `app/google-services.json`.
  2. `RELEASE_KEYSTORE_BASE64` : Giải mã Keystore cố định để ký các bản dựng APK
     mà KHÔNG bao giờ bị thay đổi chứng chỉ SHA-1 và SHA-256 giữa các lần build.

--------------------------------------------------------------------------------
PHẦN 1: DANH SÁCH CÁC GITHUB SECRETS CẦN THIẾT LẬP
--------------------------------------------------------------------------------

Vào kho lưu trữ (Repository) trên GitHub của bạn:
  Settings -> Secrets and variables -> Actions -> Nhấn nút "New repository secret"

Bạn cần tạo 2 Secret bắt buộc sau:

1. `GOOGLE_SERVICES_JSON` (Bắt buộc)
   - Nội dung: Chuỗi Base64 (hoặc toàn bộ nội dung văn bản JSON gốc) của tệp
     `app/google-services.json`.
   - Công dụng: Bước "Restore google-services.json from GitHub Secret" trong
     `.github/workflows/build.yml` sẽ tự động khôi phục tệp `app/google-services.json`
     trước khi biên dịch.

2. `RELEASE_KEYSTORE_BASE64` (Bắt buộc)
   - Nội dung: Chuỗi mã hóa Base64 của tệp keystore dùng để ký ứng dụng.
   - Công dụng: Kho lưu trữ không còn lưu bất kỳ tệp keystore nào. GitHub Actions
     sẽ giải mã `RELEASE_KEYSTORE_BASE64` để ký cho cả bản dựng thông qua cùng
     một chứng chỉ SHA-1 & SHA-256 duy nhất, đảm bảo Google Sign-In (Credential
     Manager), Firebase Auth và việc cập nhật ứng dụng trên Uptodown hoạt động
     ổn định.

3. Các Secret tùy chọn (chỉ cần nếu bạn tạo Keystore với mật khẩu/alias riêng):
   - `RELEASE_STORE_PASSWORD` : Mật khẩu của kho khóa
   - `RELEASE_KEY_ALIAS`      : Tên bí danh khóa (alias)
   - `RELEASE_KEY_PASSWORD`   : Mật khẩu của khóa
   *(Lưu ý: Nếu bạn tạo keystore với mật khẩu `wifidirectchat` hoặc `android`,
   workflow sẽ tự động nhận diện mà không bắt buộc phải khai báo 3 biến phụ này).*

--------------------------------------------------------------------------------
PHẦN 2: CÁCH TẠO VÀ LẤY GIÁ TRỊ CHO `RELEASE_KEYSTORE_BASE64`
--------------------------------------------------------------------------------

Bước 1 — Tạo tệp Keystore cố định trên máy tính của bạn (chỉ làm 1 lần duy nhất):
  Chạy lệnh sau trong Terminal / PowerShell:

    keytool -genkeypair -v \
      -keystore release.keystore \
      -alias wifidirectchat \
      -keyalg RSA \
      -keysize 2048 \
      -validity 10000 \
      -storepass wifidirectchat \
      -keypass wifidirectchat \
      -dname "CN=Thazh Share, OU=Mobile, O=Thazh, L=Hanoi, S=HN, C=VN"

Bước 2 — Lấy mã băm SHA-1 và SHA-256 cố định để đăng ký lên Firebase:
    keytool -list -v \
      -keystore release.keystore \
      -alias wifidirectchat \
      -storepass wifidirectchat

  -> Sao chép 2 dòng **SHA1** và **SHA256** trong mục `Certificate fingerprints`.
  -> Mở Firebase Console -> Project Settings -> Your apps (`com.thazh.share`) ->
     Nhấn "Add fingerprint" -> Dán SHA-1 và SHA-256 vào -> Tải lại tệp
     `google-services.json` mới nhất.

Bước 3 — Mã hóa tệp `release.keystore` sang chuỗi Base64:
  - Trên Linux / Git Bash:
      base64 -w 0 release.keystore
  - Trên macOS:
      base64 -i release.keystore | tr -d '\n'
  - Trên Windows (PowerShell):
      [Convert]::ToBase64String([IO.File]::ReadAllBytes("release.keystore"))

  -> Sao chép toàn bộ chuỗi Base64 thu được và dán vào GitHub Secret có tên:
     `RELEASE_KEYSTORE_BASE64`

--------------------------------------------------------------------------------
PHẦN 3: CÁCH LẤY GIÁ TRỊ CHO SECRET `GOOGLE_SERVICES_JSON`
--------------------------------------------------------------------------------

Bạn có thể lưu `GOOGLE_SERVICES_JSON` dưới dạng **Base64** (khuyên dùng) hoặc
**JSON thuần (Raw JSON)**:

Cách A — Mã hóa Base64 (Khuyên dùng):
  - Trên Linux / Git Bash:
      base64 -w 0 app/google-services.json
  - Trên macOS:
      base64 -i app/google-services.json | tr -d '\n'
  - Trên Windows (PowerShell):
      [Convert]::ToBase64String([IO.File]::ReadAllBytes("app\google-services.json"))

  -> Sao chép toàn bộ chuỗi kết quả và dán vào Secret `GOOGLE_SERVICES_JSON`.

Cách B — Dán trực tiếp nội dung JSON:
  - Mở tệp `app/google-services.json` bằng trình soạn thảo văn bản.
  - Sao chép toàn bộ nội dung (từ dấu `{` đầu tiên đến dấu `}` cuối cùng) và dán
    vào Secret `GOOGLE_SERVICES_JSON`.

--------------------------------------------------------------------------------
PHẦN 4: CÁCH THÊM SECRET TRÊN GIAO DIỆN WEB GITHUB (TỪNG BƯỚC)
--------------------------------------------------------------------------------

  Bước 1: Mở trình duyệt và truy cập vào repository GitHub của bạn.
  Bước 2: Nhấn vào tab "Settings" (biểu tượng bánh răng ở thanh menu trên cùng).
  Bước 3: Ở thanh menu bên trái, kéo xuống mục "Security", nhấn vào
          "Secrets and variables" -> chọn "Actions".
  Bước 4: Nhấn nút màu xanh "New repository secret" ở góc trên bên phải.
  Bước 5:
    - Ô "Name"   : Nhập chính xác tên biến (`RELEASE_KEYSTORE_BASE64` hoặc
                   `GOOGLE_SERVICES_JSON`).
    - Ô "Secret" : Dán giá trị tương ứng vào.
    - Nhấn nút "Add secret" để lưu.

--------------------------------------------------------------------------------
PHẦN 5: KIỂM TRA HOẠT ĐỘNG TRÊN GITHUB ACTIONS
--------------------------------------------------------------------------------

Sau khi thiết lập xong 2 Secrets (`GOOGLE_SERVICES_JSON` và `RELEASE_KEYSTORE_BASE64`):
  1. Vào tab "Actions" trên kho lưu trữ GitHub của bạn.
  2. Chọn workflow "Build APK" ở cột bên trái.
  3. Nhấn "Run workflow" (hoặc đẩy một commit mới lên nhánh `main`).
  4. Hệ thống sẽ tự động:
     - Khôi phục `app/google-services.json` từ Secret `GOOGLE_SERVICES_JSON`.
     - Giải mã Keystore từ Secret `RELEASE_KEYSTORE_BASE64`.
     - Biên dịch và ký số APK với chứng chỉ SHA-1 / SHA-256 cố định của bạn.
